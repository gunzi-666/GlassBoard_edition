# GlassBoard

**v0.9.17 测试版** · Windows 10 / 11（64 位）· GPL-3.0 开源

**把散在桌面上的图标收进一条悬浮的 Dock，桌面只留壁纸。**
# 这是什么
GlassBoard 是一个 Windows 桌面整理与美化的小工具。装好之后，你的屏幕上会多出三样东西：

- 屏幕边缘一条**会自动浮现的图标栏**（Dock）
- 一个能一屏看到全部程序的**「大面板」**
- 可以摆在桌面任意位置的**时钟组件**

桌面上的快捷方式可以全部拖进 Dock 和面板里，从此桌面只剩壁纸。

![GlassBoard Dock](docs/images/dock.png)

它适合这几类人：

- 桌面图标堆到看不清壁纸，又懒得一个个归类
- 喜欢半透明毛玻璃的观感，但不想换系统主题、不想折腾美化包
- 工作和娱乐用两套程序，每次都要一个个点开，很烦

**和系统自带的任务栏有什么区别？**
任务栏只能放一行，满了会挤；Dock 可以分组、可以搜索、可以整套切换。两者也不冲突——GlassBoard 甚至能顺手把系统任务栏自动隐藏，让桌面更干净。

## 它能做什么

### 一、把桌面收干净

- **Dock 图标栏**：桌面图标拖进去就固定，点一下启动，不想要了拖走
- **大面板**：点 Dock 最左边的按钮，一屏看到全部程序
- **自动分组**：按规则自动分好组，也能自己建组、改名、拖动排序
- **搜索**：面板顶部直接打字找程序，不用记它在哪个分组
- **批量导入**：托盘右键「导入开始菜单应用」，一次把装机软件全收进来
- **批量整理**：面板里可以跨页勾选、一次移除多个入口；删错了按 `Ctrl+Z` 撤销

### 二、让桌面好看

- **玻璃材质**：材质种类、色调、光泽、纹理、阴影都能调，只改背景，图标和文字保持清晰
- **深浅两套**：一个开关切换浅色玻璃
- **外观方案**：调好的一套皮肤能存成方案随时切回来，也能导出成文件分享给别人
- **桌面组件**：时钟摆在桌面任意位置，独立拖动

### 三、按场合一键切换

- **工作区**：把「要开的程序 + 素材文件夹 + 项目文件」存成一个工作区，下次一键全部打开
- **隐藏任务栏 / 桌面图标**：想要纯净桌面时一键藏起来，需要时再一键恢复

### 四、不给你添麻烦

- **全屏自动让位**：看视频、打游戏时 Dock 和面板自动隐藏，退出后自动回来
- **闲置省内存**：几分钟没操作就回收内存，实测空闲只占 5–10MB
- **开机自启**：可选，随时能在设置里关掉
- **备份恢复**：布局、分组、外观、图标打成一个文件，换电脑或重装都能还原

## 安装（三步）

### 第 1 步：解压到一个新文件夹

右键压缩包 → **全部解压缩** → 选一个空文件夹，比如 `D:\GlassBoard`。

> ⚠️ 必须整个文件夹一起解压。只把 `GlassBoard.exe` 拖出来会打不开。

### 第 2 步：双击启动

进入解压出来的文件夹，双击 **`GlassBoard.exe`**（或 `Start.cmd`）。

### 第 3 步：如果弹出蓝色警告

Windows 提示「已保护你的电脑」时：

点 **更多信息** → **仍要运行**。

这是因为程序没有购买数字签名，不是有毒。每次换新版本第一次运行时可能都会问一次。

## 杀毒软件报毒怎么办

大概率会报。原因有两个，都不是恶意行为：

1. 程序没有购买数字签名（签名证书每年要花钱）
2. 它会读取「当前正在运行哪些程序」，用来在 Dock 上显示运行状态

处理办法：在杀毒软件里把它加进**信任区 / 白名单**，不要为此关掉整个杀毒软件。
程序不会上传任何数据，联网用途见「隐私与联网」。

## 五分钟上手

| 想做的事 | 怎么做 |
| --- | --- |
| 找到 Dock | 鼠标移到屏幕边缘，它就浮出来 |
| 打开大面板 | 点 Dock **最左边**的按钮 |

| 找配置文件 | 托盘右键 →「打开配置文件夹」 |
| 让任务栏自动隐藏 | 托盘右键 →「Windows 任务栏自动隐藏」 |
| 退出程序 | 托盘右键 →「退出 GlassBoard」 |

> 托盘图标在右下角任务栏里，可能被折叠进 `^` 里，点一下展开就能看到。

## 更新

**设置 → 通用 → 软件更新 → 立即检查**。

- 有新版本会显示版本号和大小，点「下载并更新」，程序会自己退出、替换、重启
- 更新只替换程序文件，你的布局和分组会保留，替换前自动备份
- 检查更新失败：多半是网络问题。可以在同一页把「使用 Windows 系统代理」切成「直接连接」再试
- 还是失败：`托盘右键 → 打开配置文件夹`，看里面的 `update.log`，里面逐条记录了每条线路的结果

## 备份与恢复

**设置 → 通用 → 完整备份与恢复**

- **导出完整备份**：把布局、分组、组件、外观方案和自定义图标打成一个 `.gbbackup` 文件
- **恢复完整备份**：导入这个文件即可还原；恢复前会把当前配置自动另存一份

程序出问题打不开时，用文件夹里的三个小工具（双击即可）：

| 文件 | 什么时候用 |
| --- | --- |
| `RecoverWidgets.cmd` | 组件不见了、位置乱了 |
| `RestoreDesktop.cmd` | 任务栏或桌面图标被隐藏了、显示不出来 |
| `CollectDiagnostics.cmd` | 要反馈问题：把日志打包到桌面，方便发给作者 |

## 关闭开机自启 / 彻底卸载

1. 打开 **设置 → 桌面组件**，关掉「开机自启动」
   （这一步必须在前，否则删了文件夹还会留一个开机任务）
2. 托盘右键 →「退出 GlassBoard」
3. 直接**删除整个程序文件夹**
4. 想连配置一起清掉：托盘右键 →「打开配置文件夹」，删除整个 `GlassBoard` 文件夹

## 常见问题

**双击没反应 / 窗口一闪就没了**
先确认解压了**整个**文件夹；再双击 `Start.cmd` 看有没有中文报错提示。

**提示「已保护你的电脑」**
点「更多信息 → 仍要运行」，见安装第 3 步。

**杀毒软件提示有风险**
见「杀毒软件报毒怎么办」，加信任即可，不要关闭杀软。

**Dock 不见了**
1. 鼠标移到屏幕边缘扫一圈；2. 右键托盘图标看有没有勾选「隐藏」；3. 双击 `RecoverWidgets.cmd`。

**看完全屏视频 / 打完游戏，Dock 没回来**
等两三秒；还不回来就双击 `RecoverWidgets.cmd`，或在托盘右键里「恢复并开启全部组件」。

**图标变成白纸 / 空白**
右键该图标 →「恢复原图标」。自定义图标丢了的话，用备份文件还原。

**副屏图标发虚**
程序按主屏的缩放比例渲染，副屏缩放比例不同就会糊，这是已知限制，暂时没法彻底解决。

**内存占用看着很高**
这是 Windows 的「工作集」显示方式。程序闲置几分钟会自己回收，实测空闲可降到 5–10MB。

**检查更新一直失败**
换「直接连接」再试，或者挂代理；详见「更新」一节。

**卸载后任务栏 / 桌面图标不见了**
双击 `RestoreDesktop.cmd`，或重新打开程序用托盘菜单「恢复任务栏与桌面图标」。

## 出问题怎么反馈

1. 双击程序文件夹里的 `CollectDiagnostics.cmd`
2. 桌面会生成 `GlassBoard_Diagnostics_日期时间.zip`
3. 到 [Issues](https://github.com/xinxiao1011/GlassBoard/issues) 新建一条，把 zip 拖进去，再补三句话：

   - 系统是 Win10 还是 Win11，是不是多显示器
   - 出问题前你做了什么（点了什么、开了什么程序）
   - 现象是什么（最好附一张截图）

> 日志里只有程序自己的运行记录和你的配置，不含账号密码，也不含你其他文件的内容。

## 隐私与联网

- 不需要注册账号，没有登录，没有使用统计（无遥测）
- 你的布局、分组、图标都只存在本机 `%LOCALAPPDATA%\GlassBoard\`，不会上传
- 联网只用于两件事：
  1. **检查更新**：访问 GitHub 的项目地址，判断有没有新版本
  2. **天气组件取数据**（如果你启用了它）：把城市名发给公开天气服务
- 全程使用 HTTPS，不经过任何第三方服务器

---

## 已知限制

- **不同缩放比例的多显示器**：副屏可能发虚，位置也可能偏
- **独占全屏的游戏**：少数游戏会吞掉 Win+D，导致「显示桌面」失效
- **测试版**：功能还在改，界面可能变，配置格式也可能调整
- **在线更新会覆盖手工改动**：如果你自己替换过 exe，更新后会被官方版本覆盖

## 给会写代码的人

```bat
cd source
dotnet build GlassBoard.csproj -c Release
```

需要 .NET SDK 8 或更高。产物在 `source\bin\Release\net48\GlassBoard.exe`。

更新助手 `GlassBoard.Updater.exe` 由 `source\GlassBoard.Updater` 编译，与主程序共用 `UpdateApply.cs` 等更新校验代码：

```bat
dotnet build source\GlassBoard.Updater\GlassBoard.Updater.csproj -c Release
```

替换运行时只需把新的 `GlassBoard.exe` 覆盖到程序目录，**不要**只把这个 exe 放进空文件夹——
程序还需要同目录下的 `Interop.UIAutomationClient.dll`、`data\`、`src\` 和 `GlassBoard.Updater.exe`。

仓库结构：

| 目录 | 内容 |
| --- | --- |
| `source/` | 可编译的 C# 源码（Visual Studio / `dotnet build`） |
| `src/` | 随程序发布的 PowerShell 诊断脚本 |
| `data/` | 应用分组对照表等数据文件 |
| `patches/` | 维护过程中用到的工具与打包产物，普通使用不需要 |
